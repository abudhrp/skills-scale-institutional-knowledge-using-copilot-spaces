# OctoAcme Project Management Processes

Welcome to the OctoAcme project management documentation hub. This folder contains comprehensive guides for running projects using the OctoAcme approach.

## Quick Overview

OctoAcme is a customer-first, iterative project delivery framework built on clear ownership, data-informed decisions, and psychological safety. All projects follow a standardized lifecycle from initiation through retrospective.

Our core principles ensure that:
- **Customer-First**: We prioritize customer value in every decision
- **Iterative Delivery**: We deliver value in shippable increments
- **Clear Ownership**: Every task has a clear owner who is accountable
- **Data-Informed Decisions**: We use metrics and feedback to guide our work
- **Psychological Safety**: Team members feel safe to take risks and voice concerns

### Project Lifecycle at a Glance

1. **Initiation** → Define business need, align stakeholders
2. **Planning** → Break work into shippable increments, identify risks
3. **Execution** → Build, test, review, iterate daily
4. **Release** → Deploy to production with verification
5. **Retrospective** → Capture learnings and improve

## Key Roles

The OctoAcme framework defines clear roles to ensure accountability and smooth execution:

- **Project Manager (PM)** — Owns overall project delivery, stakeholder alignment, and risk management
- **Product Manager (PdM)** — Owns customer voice, requirements prioritization, and success criteria
- **Developers** — Own implementation quality, technical decisions, and code reviews
- **QA** — Owns quality standards, testing strategy, and release verification
