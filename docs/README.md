# OctoAcme Project Management Processes

Welcome to the OctoAcme project management documentation hub. This folder contains comprehensive guides for running projects using the OctoAcme approach.

## Overview

OctoAcme is a customer-first, iterative project delivery framework designed to deliver value consistently while maintaining team well-being and quality. Built on core principles of clear ownership, data-informed decisions, and psychological safety, OctoAcme enables teams to execute with confidence and transparency.

### Core Principles

- **Customer-First Mindset**: Every decision centers on customer value and outcomes
- **Iterative Delivery**: Break work into shippable increments and deliver continuously
- **Clear Ownership**: Defined roles and responsibilities ensure accountability
- **Data-Informed Decisions**: Use metrics and evidence to guide project direction
- **Psychological Safety**: Foster an environment where team members can take risks and learn

### Key Roles

- **Project Manager (PM)**: Owns day-to-day execution, team coordination, and blockers
- **Product Manager (PdM)**: Owns product direction, prioritization, and customer alignment
- **Developers**: Execute technical work, estimate scope, and ensure code quality
- **QA**: Validate quality, manage test strategy, and ensure release readiness

## Project Lifecycle at a Glance

OctoAcme projects follow a standardized five-phase lifecycle:

1. **Initiation** → Define business need, align stakeholders, create project one-pager
2. **Planning** → Break work into shippable increments, identify risks, build release plan
3. **Execution** → Build, test, review, iterate daily with standups and sprint workflows
4. **Release** → Deploy to production with verification, manage rollback if needed
5. **Retrospective** → Capture learnings, identify improvements, feed into future planning
