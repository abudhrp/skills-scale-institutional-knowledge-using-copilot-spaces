# OctoAcme Project Management Processes

Welcome to the OctoAcme project management documentation hub. This folder contains comprehensive guides for running projects using the OctoAcme approach.

## Quick Overview

OctoAcme is a **customer-first, iterative project delivery framework** built on five core principles:

- **Customer-first**: Prioritize customer value and usability in every decision
- **Iterative delivery**: Deliver small, testable increments frequently
- **Clear ownership**: Every project has named leaders accountable for outcomes
- **Data-informed decisions**: Measure impact and iterate based on evidence
- **Psychological safety**: Encourage feedback, learning, and continuous improvement

All OctoAcme projects follow a standardized lifecycle from initiation through retrospective, with consistent roles (Project Manager, Product Manager, Developers, QA, and Stakeholders) collaborating to deliver results.

## Project Lifecycle at a Glance

1. **Initiation** → Define business need, validate customer problem, align stakeholders
2. **Planning** → Break work into shippable increments, estimate scope, identify risks
3. **Execution** → Build, test, review, iterate daily with feedback loops
4. **Release** → Deploy to production with verification and rollout procedures
5. **Retrospective** → Capture learnings, celebrate wins, and improve processes

## Key Artifacts Used Across All Projects

- **Project Charter / One-pager** — Executive summary of the project
- **Roadmap and Release Plan** — High-level delivery timeline
- **Sprint/Iteration Backlog** — Work items for current sprint
- **Acceptance Criteria & Definition of Done** — Quality standards and completion criteria
- **Risk Register** — Identified risks and mitigation strategies
- **Retrospective Notes** — Learnings and action items for next projects

## Communication Cadence

- **Weekly sync** between Project Manager and Product Manager
- **Twice-weekly standups** for delivery team (or as agreed by team)
- **Monthly stakeholder updates** to keep leadership informed
- **Ad-hoc escalations** as needed for urgent issues
